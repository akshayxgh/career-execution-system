# Extension Canonical Path Rule

- The canonical Chrome extension path is strictly: `D:\Vs Code\form_filler_chrome_extension\job-autofill`.
- All Chrome extension edits, additions, and updates MUST be performed on `D:\Vs Code\form_filler_chrome_extension\job-autofill`.
- Keep `D:\Vs Code\career-execution-system\extension` mirrored so git version control remains in sync.
- Always increment the version in `manifest.json` and update `CHANGELOG.md` upon modifying extension files.

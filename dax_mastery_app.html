Time Intelligence

Robust Prior Year & YoY Growth %

Total Sales = SUM(FactSales[SalesAmount])

Sales PY = 
CALCULATE(
    [Total Sales],
    SAMEPERIODLASTYEAR(DimDate[Date])
)

YoY Sales Growth % = 
DIVIDE(
    [Total Sales] - [Sales PY],
    [Sales PY]
)
Modern Window

Month-over-Month with OFFSET (2024)

Sales Prior Month (Offset) = 
CALCULATE(
    [Total Sales],
    OFFSET(
        -1,
        ALLSELECTED(DimDate[YearMonth], DimDate[MonthNumber]),
        ORDERBY(DimDate[MonthNumber], ASC)
    )
)
Filter Context

Safe % of Visual Total (ALLSELECTED)

Sales % of Selected Total = 
VAR CurrentSales = [Total Sales]
VAR TotalSelectedSales = 
    CALCULATE(
        [Total Sales],
        ALLSELECTED(DimProduct)
    )
RETURN
    DIVIDE(CurrentSales, TotalSelectedSales)
